## 五、事实守恒 suggestion 的最终边界

系统支持事实守恒的内容级表达优化，包括：

- 措辞精简；
- 语序调整；
- 同义表达；
- 突出原文已有的岗位相关信息。

自然语言 suggestion 必须同时通过：

1. 后端确定性校验，包括原始段落、证据范围、数字、明显英文技术或产品词、职责升级和能力强度升级；
2. 独立 suggestion 事实审校。

不允许新增原文没有的技术栈、职责、项目、公司、职位、年限、数字、成果或能力强度。被判定为 blocked 的 suggestion 没有 `suggested_text`，不能写入 Draft。该机制用于尽量阻止事实幻觉，不宣称完全消除自然语言模型的不确定性。

## 六、保存、预览与导出

已验证：

- Resume 原稿与 Draft 分离；
- suggestion 接受只更新 Draft；
- suggestion 忽略不修改正文；
- 重复接受保持幂等；
- 手工编辑只改变 working draft；
- 显式保存创建 immutable saved revision；
- Preview 与 Markdown export 只读取保存版本；
- 导出不混入分析 reason、warning、confirmation question 或 ignored suggestion；
- 历史版本恢复不会覆盖或删除旧 revision。

## 七、已知限制

1. 外部模型调用受认证、限流、超时和服务可用性影响，失败后需要用户显式 retry。
2. 自然语言事实判断仍包含模型不确定性；无法确认安全时会阻止自动采纳。
3. `needs_confirmation` 表示当前材料证据不足，不代表求职者一定没有该能力。
4. restore 只恢复历史正文到 working draft，不恢复历史 suggestion decision 状态。
5. 当前只支持文字简历与文字岗位描述。
6. OCR、PDF 解析与排版、招聘网站抓取、自动投递、面试、排行榜、评分和多模板编辑器不在题目范围内。
