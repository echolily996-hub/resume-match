# FINAL-D 信息缺口场景岗位

> 虚构验收素材。建议在应用中将岗位名称填写为：`FINAL-D-云原生后端工程师`。

## 岗位职责

- 使用 Python 和 FastAPI 独立负责核心 REST API 的设计与开发。
- 使用 PostgreSQL 设计业务数据结构并优化复杂查询。
- 使用 Redis 实现缓存和分布式状态管理。
- 使用 Docker 构建服务镜像，并使用 Kubernetes 完成部署和维护。
- 在 Linux 环境中排查线上服务问题。
- 跟踪接口性能指标并提供量化优化结果。

## 任职要求

- 熟悉 Python 和 FastAPI。
- 熟练使用 PostgreSQL。
- 具备 Redis 实际项目经验。
- 具备 Docker 和 Kubernetes 实际项目经验。
- 熟练使用 Linux，能够独立完成服务部署和故障排查。
- 能够独立负责后端模块，并清晰说明个人职责和量化成果。
